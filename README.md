# BiblioStock

## Descripción

BiblioStock es un sistema sencillo desarrollado en Python para gestionar el inventario y los préstamos de una biblioteca.

El sistema permite:

- Registrar ítems.
- Listar los ítems registrados.
- Buscar un ítem por título o código.
- Registrar préstamos.
- Registrar devoluciones.
- Guardar y cargar la información mediante un archivo de texto o JSON.

El proyecto se ejecuta desde la terminal y fue desarrollado como parte de una práctica de control de versiones utilizando Git y GitHub.
